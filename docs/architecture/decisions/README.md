# 技术决策记录

- 类型：决策规则与索引
- 适用范围：greeting
- 维护责任：决定涉及的模块与项目维护者
- 核对日期：2026-10-13

记录重要、难逆转或容易争议的选择：背景、考虑的方案、采用决定、后果、证据与责任文档。普通修复和测试可直接解释的实现细节无需逐项建立决策。一个决定一个文件，用顺序编号和主题名。

| 状态 | 使用方式 |
| --- | --- |
| Proposed | 待确认，不作为生效实施要求 |
| Accepted | 在声明范围采用，长期规则以责任文档为准 |
| Superseded | 已替代，链接新决定 |
| Rejected / withdrawn | 未采用或不再推进，保留原因 |

改变已采用决定时增加记录并建立替代关系，保留原背景。决定不授权额外提交、发布或部署；目录与维护要求见 [文档规范](../../documentation-standard.md)。
