## 状态与创建

Draft 为待讨论，Approved/In progress 只指导相应已授权任务；Completed 是已完成历史，Superseded/abandoned 保留替代关系或原因。有阻塞写清影响，不虚报完成；计划不增加提交、推送或部署授权。

make task NAME=order-create 使用 [任务模板](task-template.md)，创建并索引 docs/plans/order-create.md，拒绝覆盖、非法/临时名称和损坏索引。填写范围后同步状态，交接前更新进度和下一步。

## 完成与正式文档回写

长期需求回写 requirements，设计/数据/安全回写 architecture，接口/配置回写 interfaces，开发与交付规则回写相应 README。登记责任文档链接、实际验证与未验证范围；无长期变化说明理由，同步索引归组。

规范见 [文档维护](../documentation-standard.md)，实施方法见 [开发指南](../development/README.md)。
